# Manual for the Galactic Space Farer Administration System

Hey there, Star Sailor! 

The purpose of this Galactic System is be your go-to when you need intel about your fellow space adventurers.

## Blasting off

In order to establish a link to the Galactic Database of your fellow space adventurers', provide your terminal with the following instructions:

```
npm install;
cds deploy --to sqlite;
npm run start;
```

## Anti-pirate efforts

This Galactic Information System deploys the appropriate security measures to prevent cyberspace pirates and illicit deck punchers from accessing valuable information not belonging to them.

Before you are granted access to any of the Galactic Archives, you will be required to identify yourself.

Be advised: You may only access data of fellow Cosmonauts originating the same planet as yourself.

> [!warning]
> ### For system maintainers only
> look up your [package.json](./package.json) file and search for the `cds.requires.auth.users` key if you need a quickfix for hotwiring the security system.
> 
> **Never let hackers get a hold of this information!**

## Accessing the system

Once your link is operational and you made sure that no unauthorized sentient creature or autonomous software is within arm and/or tentacle (whichever applies) distance of your preferred communication device, point your information accessor to the following address to start using the Archive:

[http://localhost:4004/spacefarerslistui/index.html](http://localhost:4004/spacefarerslistui/index.html)

**Happy browsing, and never forget your towel!**
